# My changes to the article builder

Newest last. Each change alters wording or emphasis only, never a truth rule.

## 2027-03-29 (Week 8 lab, Maya Patel)

- Instruction: Never call a plan a result.
- Why: the article's next step is a plan, one more small trial, with its size, dates and people not known yet. It must never read as something that has already worked.
- Tricky example: "Our plan to run a second small trial is already making a difference to how people work."
- Test showed: the first result left the plan as a plan and said we do not know yet whether it will change how people work. The second did the same and added the trial's purpose from the master story. The plan was never called a result either time. The first result was already right, because the builder's truth rules already say a plan is never written as a result. The instruction makes that rule explicit.
